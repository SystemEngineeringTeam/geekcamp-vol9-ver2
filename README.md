# Chord Cards

作曲初心者が、楽譜の知識がなくても感覚的にコード進行（和音の並び）を作れるWebアプリです。700種類以上のコードがカードとして並んでおり、音を聴きながら選んだカードを並べて、続けて再生できます。

このリポジトリは、2022年12月のハッカソン「【オンライン開発合宿vol.9】はじめてのハッカソン」で開発した最初の版を、入賞チームが招待される「【23年3月】技育CAMPアドバンス」に向けて改良した版です。最初の版の「コードが多すぎて目的のものを探しにくい」という反省をもとに、鍵盤を使ってコードを探したり、並べたコードを編集したりする機能を加えました。

React、Next.js、TypeScriptで開発し、Vercelで公開しています。
